# 小站财经 (stock)

仿 QQ.com / 163.com 门户风格的**个人财经门户**：左侧财经头条，右上角股票自选小窗，支持自定义股票。

纯静态、零后端、零依赖，可直接用 GitHub Pages 或 EdgeOne Pages 部署。

## 特性

- 📰 **左侧财经头条**：多栏目密集列表（宏观 / 证券 / 公司 / 基金 / 国际 / 房产），数据在 `assets/news-data.js`，可自行替换为真实 RSS。
- 📈 **右上角自选小窗**：腾讯财经实时行情（秒级），红涨绿跌；东方财富 JSONP 兜底。
- ✏️ **自定义股票**：点小窗「编辑」，每行一个代码（`sh600519` / `sz300750` / `hk00700` / `bj8xxxxx`），存 localStorage。
- 🔄 **自动刷新**：交易时段每 8 秒，非交易时段每 60 秒。
- 🚫 **无需后端**：行情通过 `<script>` 注入 + JSONP 绕过浏览器跨域限制，所以**静态托管即可用**。

## 文件结构

```
stock/
├── index.html         门户框架（顶栏 / 导航 / 两栏布局 / 弹窗）
├── assets/
│   ├── style.css       仿门户样式（红导航 + 蓝链接）
│   ├── news-data.js    左侧新闻数据（改这里换头条）
│   ├── news.js         左侧新闻渲染
│   └── stock.js        股票小窗（行情获取 / 自定义 / 轮询）
└── README.md
```

## 本地预览

```bash
cd stock && python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 部署

- **GitHub Pages**：push 到 `xhjxhjcn/stock`，仓库 Settings → Pages → 选 `main` 分支 `/root`。
- **EdgeOne Pages（国内更快）**：导入该仓库，构建命令留空，输出目录 `.`，与 `tools.xhja.cn` 同一套流程。

## 股票代码格式

| 市场 | 前缀 | 示例 |
|---|---|---|
| 上海 | `sh` | `sh600519`（贵州茅台） |
| 深圳 | `sz` | `sz300750`（宁德时代） |
| 北交所 | `bj` | `bj830799` |
| 港股 | `hk` | `hk00700`（腾讯控股） |

指数：`sh000001`（上证）、`sz399001`（深成指）、`sz399006`（创业板）。

## 行情源说明

- 主源：腾讯 `qt.gtimg.cn`（公开、无需 Referer，`<script>` 注入读取全局变量 `v_<code>`）。
- 兜底：东方财富 `push2.eastmoney.com` JSONP（`ulist.np.get`，仅主源个别缺失时触发）。
- 数据仅供参考，不构成投资建议。
